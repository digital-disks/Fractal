# Fractal

### An SVG to TrueType Font Converter made in C++ 23

- No Dependencies: Meaing you can run this without any additional app or library.
- No Operating System Restriction: You can run this on Windows, Mac, Linux or any other operating system. (Small Endian systems only which are basically modern CPUs)

## Why I made this?

Because I was making a custom rice shell for my Linux setup, and I wanted to be able to display almost all app icons with the ability of controlling them but there was no an icon pack font that had all app icons (Almost impossible) and SVGs were difficult to deal with because Qt fails at this for some reason. Anyways, I made this to convert SVGs on the fly and display them and recolor them instantly.
